# 💼 Yatırımcı Medya Klasörü

Bu klasöre yatırımcı sunumu için gerekli dosyaları yükleyebilirsiniz:

## 📁 Desteklenen Dosya Türleri:

### 📄 Belgeler
- **PDF**: Sunumlar, finansal raporlar, iş planları
- **PowerPoint**: Sunum dosyaları (.pptx)
- **Word**: Detaylı raporlar (.docx)

### 🎥 Medya Dosyaları
- **Video**: Platform demoları, CEO pitch videoları (.mp4, .mov)
- **Ses**: Pitch kayıtları, açıklamalar (.mp3, .wav)
- **Resim**: Ekran görüntüleri, grafikler (.jpg, .png)

## 📋 Önerilen Dosyalar:

1. **Ana Sunum**: `Dinletiyo_Yatirimci_Sunumu_2024.pdf`

## 🚀 Kullanım:
